# Alpha158 网格与"昨日因子"验证（全链淘汰）

> 日期：2026-09-12  
> 状态：**全部候选未通过验证，Champion 18 因子不变**  
> 问题来源：不移除 overnight_gap 的前提下，Alpha158 中是否有能提高收益的因子  
> 产物：`data/{alpha158_grid,combo_screen,final_portana,purged_rolling}_result.csv`；
> 实验 `alpha158_grid(_w2)`、`combo_w1/w2`、`final_portana_w1/w2`、`purged_rolling`

## 方法：四层验证漏斗

1. **网格**：85 候选（71 个 Alpha158@T-1 + 14 个 champion 分钟字段@T-1，全部
   `Ref(·,1)` 防前视）逐个叠加成 19 因子，手动 TD0 口径（09:41 买 top10 →
   次日收盘卖，含成本）W1 筛选；
2. **组合**：4 个双窗赢家（vol3m_y / acc3m_y / VSUMD10 / VSTD10）的两两组合
   与全家桶，W1+W2 双窗；
3. **PortAna 终判**：3 个决赛者完整 TD0 回测（涨跌停拦截/n_drop/成本）双窗；
4. **purged rolling**：19 个滚动段（train90/valid20/embargo1/test20，覆盖
   2025-01→2026-07）× 3 变体逐段对照。

两个方法论修正（本日志的重要副产品）：
- **幸存者偏差**：手动回测的价格查询必须用全量代码列表直查 bin（§36.3 同款
  坑）——按股池查询时次日掉池股全部丢失，日收益被抬高 ~5.5%/日；
- **训练运行噪声**：同配置跨进程重训的 champion IC 在 0.049~0.055 间波动
  （对应 PortAna 超额 ±17pp）——单次运行 ±10pp 级差异不可作为判据。

## 结果漏斗

| 层 | 进入 | 通过 | 淘汰原因 |
|---|---|---|---|
| 网格 W1 | 85 | 14 超基线(+49.8%) | VSUMP10/CNTD5 等 W2 转负 |
| 双窗 | 14 | 4 | 单窗过拟合（含 vol3m_y+acc3m_y 组合 W2=-2.3%） |
| PortAna 双窗 | 4 | **1（vol3m_y）** | ALL4 W1+99% 但 W2 输基线；acc3m+VSUMD10 W2 输 9pp |
| purged rolling | 2 | **0** | vol3m_y 段胜率 53%、均值差 -0.25%（与基线打平）；ALL4 段胜率 37%、均值差 -1.55%/段（稳定更差） |

purged rolling 明细（19 段超额 vs champion 差）：

```text
vol3m_y: 胜率 53%  均值差 -0.25%  中位 +0.18%  最差 -6.6%  最好 +5.3%  → 无边际
ALL4:    胜率 37%  均值差 -1.55%  中位 -3.82%  最差 -13.9% 最好 +16.5% → 更差
```

## 结论

1. **Alpha158 日频因子与"昨日分钟因子"均不能稳定提高收益**——W1 的亮眼表现
   在 W2/PortAna/滚动段逐层蒸发，是多重比较 + 单窗过拟合的典型形态，与 §19.1
   （85 维稀释）结论一致；
2. **Champion 18 因子的相对稳健性再次得到确认**（19 个滚动段 6 段正超额中
   仍为最强基线）；
3. 发现的训练运行噪声（±0.006 IC）意味着今后任何 A/B 结论都应：同批重跑基线
   对照 + 多段滚动，单窗口单次运行的差异不足为凭。

## 追加调研（同日）：剔除 gap 后的跨周期因子替补（同样全淘汰）

问题：把 overnight_gap 从底座剔除（17 因子），用跨多周期（1/3/5/10/20 日）
日频因子做替补（动量 MOM / 收益波动 STD / 量波动 VSTD / 距 N 日高点 HDIST /
上涨天数占比 CNT，共 25 个有效候选，全部 `Ref(·,1)` 锚定 T-1），能否补回 gap
的价值？基线同批重跑（吸取运行噪声教训）。

| 变体 | W1 超额 | W2 超额 |
|---|---|---|
| champion18（参照） | **+36.3%** | **+36.8%** |
| BASE17（无 gap 底座） | +0.05% | -7.7% |
| **STD3（3日收益波动@T-1，最佳替补）** | +15.8% | +19.0% |
| MOM1（1日动量@T-1） | +16.8% | -3.3%（单窗假赢） |
| VSTD10（10日量波动@T-1） | +16.8% | +0.04%（单窗假赢） |
| 其余 22 个 | ≤ +14% 或为负 | — |

结论：**没有任何替补能补回 gap 的价值**。最佳替补 STD3 双窗稳定但只恢复
约一半（两窗都只有 champion18 的 ~40-50%，差距 2 倍于运行噪声）；MOM1/VSTD10
是单窗假赢；MOM10/20、STD5/20 为负（长周期动量在高换手池失效，与池特性一致）。
CNT 族表达式在当前引擎下产生全 NaN（结果与底座逐位相同），记为无效候选。

**gap 的跨日信息在这个高贝塔池里具有不可替代性**——它同时编码"隔夜情绪 +
昨日收盘强弱"，而可得的日频跨周期因子只覆盖其中一部分。Champion 18 因子
继续保持冻结。
