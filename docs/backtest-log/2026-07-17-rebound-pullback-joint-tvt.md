# 反弹穿越 + 回调后共同启动：合并联合训练验证

> 保存状态：当前唯一保留的阶段共振研究方案。固定使用 23 个特征与完整 19-fold 结果；其他未晋级研究实现和数据已于 2026-07-17 清理。

## 结论

合并方案提升了固定模型的超额收益和信号质量，并比两个单独方案略微改善收益/回撤组合；但相对 champion 仍以明显更深的超额回撤换取收益，不满足生产准入。严格 validation gate 又过于稀疏，只放行 2/19 个窗口，冻结 test 超额收益反而低于基线。

## 设计

- 原 18 因子同时加入两类 T-safe 阶段交互，共 23 个特征：
  - 反弹启动、反弹 × 分钟路径斜率、反弹 × 浅回撤；
  - 回调延续、回调 × 相对强度/5 分钟加速度/分钟路径回撤联合确认。
- 19 个 purged rolling folds；每 fold 90 日 train、20 日 valid、1 日 embargo、冻结 test。
- 每 fold 独立重训 HFLGB/XGBoost；XGB 25% 混合及新特征启用均只由 valid 决定。
- 冻结 test：2025-01-02 至 2026-07-02。

## 增量判断

- 相对 champion：合并固定模型超额年化增加 8.60 个百分点，但超额最大回撤恶化 5.75 个百分点。
- 相对共同启动单独方案：超额年化增加 0.16 个百分点，超额回撤改善 0.66 个百分点，说明合并存在小幅互补，但幅度不足以解决风险问题。
- 合并模型 IC/RankIC 均为四个固定口径中最高，说明两个阶段信号在横截面排序上具有互补性。
- strict gate 只在 2/19 folds 放行。其超额最大回撤比 champion 改善 0.14 个百分点，但超额年化下降 2.96 个百分点，不能部署。

## 决策

合并假设在“提升超额收益”这一目标上成立，但完整收益—回撤准入失败。保持生产 champion 不变。下一步若继续，应针对合并模型做风险预算/暴露约束，而不是继续增加相似阶段特征。
