## 方案 A：遗传规划（GP）因子挖掘

### 思路
用遗传规划（Genetic Programming）在 18 个分钟因子上自动搜索 alpha 公式（算子树）。与方案 C 的"广撒网让 LGBM 选"不同，GP 是**用 IC 作为适应度直接进化公式**，能发现人想不到的非线性组合，并自带因子筛选（差的公式被淘汰）。

### 依赖
- `pip install gplearn`（纯 Python，~50KB，仅依赖 scikit-learn 1.8.0 已装）。装进 `qlib_ifind_beta` conda 环境。
- gplearn 是 sklearn 风格的 GP 库，支持自定义 fitness function、算子集、遗传操作（交叉/变异/选择）。

继续用 `feat/autofeature-handler` worktree（`/home/zxh/projects/qlib_autofeature`），与方案 C 平行。

### GP 设计

**输入数据**：train 段（2024 全年）的 18 个分钟因子值 + label（T+1 收益）。
- 从 qlib bin 加载为 DataFrame（index=multi-level (datetime, instrument)，columns=18 因子）
- X = 18 因子值，y = label 真实收益率
- 横截面标准化（每日 RobustZScore，防极端值干扰 GP）

**GP 配置**（`gplearn.genetic.SymbolicTransformer`）：
- `population_size=2000`（种群规模）
- `generations=20`（进化代数）
- `tournament_size=20`（锦标赛选择）
- `metric='spearman'`（自定义：每日横截面 Spearman rank IC 作为适应度）
- `function_set`：`add, sub, mul, div, log, sqrt, abs, neg, max, min`（安全版：div 防零、log/sqrt 负值保护）
- `parsimony_coefficient=0.001`（复杂度惩罚，防公式爆炸）
- `feature_names` = 18 个因子名（GP 会输出可读的公式表达式）
- `n_components=20`（最终保留 20 个最优 alpha 公式）
- `p_crossover=0.7, p_subtree_mutation=0.1, p_hoist_mutation=0.05, p_point_mutation=0.1`

**前视安全**：
- GP 只在 train 段（2024）fit，不碰 valid/test
- 进化用的 label 是 T+1 收益（已知未来），但这是**训练阶段正常的监督信号**（和 LGBM 用 label 训练一样），不是推理前视
- 产出的公式在 valid/test 段评估时只用 T 日因子值（9:30-9:40 数据），无未来信息

### 新增文件

**1. `qlib_ifind_beta/gp_factor_mining.py`** — GP 核心
- `load_training_data()` → 从 qlib bin 加载 18 因子 + label，横截面标准化
- `run_gp_evolution()` → 配置并运行 gplearn SymbolicTransformer，返回 top-N alpha 公式
- `gp_factors_to_handler_fields()` → 把 GP 产出的公式转为 qlib 表达式字符串（喂给 Handler）
- 自定义适应度函数：每日横截面 Spearman IC 均值

**2. `qlib_ifind_beta/gp_handler.py`** — GP Handler
- 继承 `HighBetaAlpha158`，`get_feature_config` 返回 GP 挖掘的 N 个 alpha 表达式
- 公式来源：`gp_factor_mining.py` 预计算并缓存的结果（避免每次构造 handler 都重跑 GP）

**3. `qrun/workflow_gp.yaml`** — GP workflow
- 仿 champion 结构，handler 指向 GPHandler，其余 FROZEN

**4. `tests/test_gp_handler.py`** — 结构测试
- 验证 GP 产出公式的合法性、唯一性、前视安全

**5. `scripts/run_gp_backtest.py`** — 轻量回测
- 复用 autofeature 的轻量回测逻辑（pred→top10→真实 label 收益），对比 GP 因子 vs champion vs autofeature

**6. `scripts/gp_factor_scoring.py`** — 综合打分
- 跑完三种因子集（champion 18 / autofeature 525 / GP N）的轻量回测后，输出综合对比表
- 维度：IC、ICIR、超额年化、IR、夏普、最大回撤、换手、因子数、best_iter

### 实现顺序
1. `pip install gplearn`（装进 conda 环境）
2. 写 `gp_factor_mining.py`（数据加载 + GP 进化 + 公式导出）
3. 跑 GP 进化，拿到 N 个 alpha 公式 → 缓存为常量
4. 写 `gp_handler.py` + 测试
5. 写 `qrun/workflow_gp.yaml` + `scripts/run_gp_backtest.py`
6. 跑 GP 回测
7. 写 `scripts/gp_factor_scoring.py` 综合打分（三方案对比）
8. 跑综合对比 → 输出最终报告

### 预期产出

- 三方案对比表：champion(18) vs autofeature(525) vs GP(~20)，含 IC/超额/IR/夏普/回撤/换手
- 综合打分结论：哪个方案最优、各自适用场景
