# 实时模拟盘信号生成系统方案

## 目标
每个交易日 9:41，用实时 9:31-9:40 分钟K线数据生成 top10 标的池信号，供用户决策。

## 架构：Option B（直接内存计算，绕过 qlib bin 物化）

### 数据流
```
9:40:00  kline-fetcher 并行拉取 ~100 只股票 × 11 bars（9:31-9:41）
         ↓
         内存构建 c/o/h/l/vol 数组（length 11）+ vwap
         ↓
         compute_day_factors() → 14 因子 + 4 extra（共 18）
         ↓
         加载 FROZEN champion 模型 → predict → top10
         ↓
9:41:00  输出标的池 CSV + 控制台摘要
```

### 关键依赖
1. **kline-fetcher** ✅ 已验证可用（`fetch_min_kline(code, count=-11)`）
2. **T-1 全天分钟量**（vol_vs_yest 分母）→ 从 `cn_data_1min` 读取已同步的 T-1 数据
3. **overnight_gap**（需要 T-1 close/factor）→ 从 `qlib_data` 日频 bin 读取
4. **FROZEN 模型** ✅ `93d435e0`（HFLGBModel champion）
5. **Universe** → 从 `data/qlib_root/instruments/highbeta883926.txt` 读取

### 新建文件
- `qlib_ifind_beta/realtime/` 实时信号模块
  - `signal.py`：核心信号生成（fetch → factors → predict → top10）
  - `data_fetch.py`：kline-fetcher 封装 + prev_day 缓存
- `scripts/realtime_signal.py`：命令行入口
- `tests/test_realtime_signal.py`：测试（mock kline-fetcher）

### 与 P1 的差异
- P1（盘后）读 `cn_data_1min` 的 bin → 物化 → qlib 预测
- 实时（盘前）：直接拉取 1min bars → 内存算因子 → qlib 预测（绕过 bin 物化）
